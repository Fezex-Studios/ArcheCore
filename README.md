# ArcheCore
### Welcome to ArcheCore
Archecore was built from the ground up with the help of Claude & Chatgpt Archetectured by me. building an MMORPG 
or any open world game should not be an impossible task. ArcheCore is a testament in itself to show Developers that 
building open world games  with modern solutions with the correct architecture can be achived and scaled without the 
need of 200 Developers my architecture does expect certain things from the developers working with archecore
such as Intermediate Experience in C# & Typescript as well as Experience with sqlite and mysql.
